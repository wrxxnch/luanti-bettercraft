# BetterCraft Commands Mod

This mod adds advanced commands to BetterCraft/Luanti, inspired by Minecraft, with support for relative coordinates and autocomplete.

## Features

- Relative and local coordinates such as `~~~`, `23 ~ 23`, and `^^^6`.
- `/execute <x> <y> <z> <command> [args]`.
- `/particle <name> <x> <y> <z>`.
- `/testfor <player>` and `/testforblock <x> <y> <z> <node>`.
- Chat autocomplete for registered commands.

## Installation

Copy the `bc_mineclonia_commands` directory into the game's `mods/` directory and enable it for the world. The `server` privilege is required to use the commands.
